# SKYlocation
site de reservation de voiture ou logement

## Administration

Le dashboard accessible sur `/dashboard` permet de modifier les éléments déjà définis dans `js/listings.js`. Les modifications sont enregistrées dans le stockage local du navigateur et ne changent pas le dépôt.

Pour ajouter une carte, copiez un objet dans le tableau `logements` ou `vehicules` de `js/listings.js`, puis publiez le site. Le bouton « Réinitialiser » efface les modifications locales et recharge les valeurs du code source.
