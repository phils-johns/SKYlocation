# SKYlocation
site de reservation de voiture ou logement

## Administration

Le dashboard accessible sur `/dashboard` permet de modifier les éléments déjà définis dans `defaultData`, dans `js/script.js`. Les modifications sont enregistrées dans le stockage local du navigateur et ne changent pas le dépôt.

Pour ajouter ou supprimer un élément pour tous les visiteurs, modifiez directement les tableaux `logements` ou `vehicules` dans `defaultData`, puis publiez le site. Le bouton « Réinitialiser » efface les modifications locales et recharge les valeurs du code source.
